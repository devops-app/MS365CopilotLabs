# Lab 00 - Set up your training files

In this lab, you confirm that the training files are accessible from OneDrive and that Microsoft 365 Copilot can reference them during exercises.

| Item | Detail |
| --- | --- |
| Level | 100 |
| Duration | 10 minutes |
| Apps | OneDrive, Microsoft 365 Copilot Chat |
| Sample folder | bp copilot / sample data |

> [!IMPORTANT]
> These labs use synthetic mock content only. Do not use real BP confidential information, employee data, supplier records, operational procedures, or restricted business data in prompts.

## Scenario

You are preparing for a BP Malaysia Copilot workshop. The instructor has uploaded mock documents to OneDrive so participants can use work-grounded prompts safely without exposing real business information.

### Exercise 1 - Confirm the folder structure

- [ ] Open OneDrive in your browser.
- [ ] Open the folder named **bp copilot**.
- [ ] Open the sub-folder named **sample data**.
- [ ] Confirm that the Word, Excel, PowerPoint, and CSV files listed in the Sample Data Inventory are visible.
- [ ] Do not move or rename the files during the lab.

> [!TIP]
> If files do not appear in Copilot file search, refresh the browser, confirm OneDrive sync, and use the file picker instead of typing the full file name.
